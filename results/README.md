# Epsilon Indi B motion result

`motion_validation.json` contains measured and catalog-predicted positions for three independent SPHEREx D6 observations. The PNGs are background-aligned display images derived from numerical FITS cutouts. Archive metadata and candidate scan files preserve the selection trail. The exact NASA/IPAC IRSA FITS URLs and quality checks are in the JSON. See `../SCIENCE_AUDIT.md` for the method, limitations, and reproduction commands.
